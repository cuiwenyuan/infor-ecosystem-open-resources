## 关键经验（可复用）
- **Google autocomplete 在本沙箱不可达**：`suggestqueries.google.com` 的 Python requests 报 ConnectTimeout，WebFetch 亦 `fetch failed`；两种通道均确认。Bing `api.bing.com/osjson.aspx?query=&language=en` 可正常返回 JSON（`[query,[suggestions]]`）。今后做搜索词采集优先用 Bing，并对 Google 明确标注"环境限制"。
- 生成大型交互页的稳妥做法：用 Python 脚本读取采集 JSON → 清洗/分类/算热度 → 直接写出 `.md`（含内嵌 DATA 与渲染脚本），避免手工拼 757 行；脚本放 `.workbuddy/tmp/` 不入库。
- 热度口径透明化：页面注明"搜索框提示相对凸显度，非真实搜索量"，避免误导。
