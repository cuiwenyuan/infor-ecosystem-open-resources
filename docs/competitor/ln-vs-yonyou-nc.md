# Infor LN vs 用友NC Cloud

> 国际高端离散制造ERP vs 中国大型集团企业数字化平台

---

## 一句话定位

| 产品 | 厂商 | 核心定位 |
|------|------|----------|
| **Infor LN** | Infor（美国） | 面向大型离散制造企业的高端ERP，以ETO/CTO/ATO复杂制造场景深度著称 |
| **用友NC Cloud** | 用友（中国） | 面向大型集团企业的新一代数字化平台，聚焦人财物客全场景，云原生架构 |

---

## 核心差异速览

| 维度 | Infor LN | 用友NC Cloud |
|------|-----------|--------------|
| **核心优势** | 复杂离散制造（ETO/CTO）、多工厂协同、全球供应链 | 集团管控（人财物客）、云原生、中国本土化深度 |
| **制造深度** | ⭐⭐⭐⭐⭐ 行业顶尖 | ⭐⭐⭐ 有制造云，但复杂ETO场景弱于LN |
| **集团财务管控** | ⭐⭐⭐ 需配合Infor d/EPM | ⭐⭐⭐⭐⭐ 核心优势，合并报表/司库/预算一体化 |
| **人力资源** | ⭐⭐ Infor HCM需单独采购 | ⭐⭐⭐⭐⭐ 数字化人力工作台，DHR升级 |
| **云原生架构** | ⭐⭐⭐ Infor OS云套件，架构偏传统 | ⭐⭐⭐⭐⭐ 云原生，支持公有云/混合云/专属云 |
| **中国本土化** | ⭐⭐ 有本地团队，但深度不及国产 | ⭐⭐⭐⭐⭐ 增值税/电子发票/金税系统深度集成 |
| **AI能力** | ⭐⭐⭐ Coleman AI（逐步推广中） | ⭐⭐⭐⭐ 融合AI/IoT/大数据，智能场景丰富 |
| **全球多语言/多币种** | ⭐⭐⭐⭐⭐ 全球160+国家本地化 | ⭐⭐⭐ 支持中企出海，覆盖广度不及LN |
| **国产化替代（信创）** | ❌ 海外厂商 | ✅ 全面适配国产芯片/OS/数据库 |
| **实施周期** | 12-18个月（复杂制造更长） | 6-12个月（云化交付加速） |
| **典型客户** | 宝马、波音、卡特彼勒、联想 | 大型集团企业、央企、国企、多业态经营集团 |

## 选型建议

### ✅ 选 Infor LN，如果——
- 你是**复杂离散制造**（航空航天、汽车、工业设备），ETO/CTO是核心需求
- 你是**跨国制造企业**，需要全球多工厂、多语言、多币种一体化管理
- 你的生产流程高度复杂，需要行业顶尖的制造深度
- 你已投入Infor生态系统（Infor OS、Infor WMS等）

### ✅ 选用友NC Cloud，如果——
- 你是**大型集团企业**，核心需求是集团财务管控+多组织协同
- 你有**国产化替代**（信创）要求
- 你需要**深度中国本土化**（金税/电子发票/会计准则）
- 你希望**更快的交付周期**和更低的TCO
- 你的主要业务在中国，全球化需求有限

### 🔀 两者结合（混合架构）
部分中企出海采用「NC Cloud（集团财务/中国运营）+ LN（海外工厂制造）」的混合模式，通过API集成实现数据打通。
