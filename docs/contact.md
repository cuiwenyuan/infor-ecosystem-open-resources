## 📝 问题反馈指南

### 报告错误（Bug Report）

**模板**：[bug-report.md](https://github.com/cuiwenyuan/infor-ecosystem-open-resources/issues/new?template=bug-report.md)

**请提供**：
- 错误描述（如：死链、错误信息、显示异常）
- 复现步骤
- 期望行为 vs 实际行为
- 环境信息（浏览器、设备、操作系统）
- 截图（如适用）

### 提交新资源（Feature Request）

**模板**：[resource-submission.md](https://github.com/cuiwenyuan/infor-ecosystem-open-resources/issues/new?template=resource-submission.md)

**请提供**：
- 资源名称
- 资源类型（论坛/顾问公司/博客/工具等）
- 资源链接
- 适用产品（Infor LN/M3/CSI 等）
- 简短描述
- 其他相关信息

详细格式请参考：[submission-guide.md](submission-guide.md)

### 提出问题（Question）

**模板**：在 [GitHub Issues](https://github.com/cuiwenyuan/infor-ecosystem-open-resources/issues/new) 中选择 "Question" 模板

**适合**：
- 如何使用本网站？
- 如何贡献内容？
- 一般性问题

## 🤝 合作意向

### 成为维护者

如果你符合以下条件，欢迎成为本项目的维护者：

- ✅ 熟悉 Infor 生态（LN/M3/CSI 等）
- ✅ 有 GitHub 使用经验
- ✅ 愿意投入时间维护项目
- ✅ 认同开源精神

**如何申请**：
1. 创建 [GitHub Issue](https://github.com/cuiwenyuan/infor-ecosystem-open-resources/issues/new)
2. 标题：`[维护者申请] 你的 GitHub 用户名`
3. 内容：简要介绍你的背景和贡献计划

### 赞助本项目
