## 🔍 搜索技巧

### Stack Overflow 搜索语法

```
# 搜索 Baan/LN 相关问题
[baan] or [infor-ln] "your keyword"

# 搜索有已接受答案的问题
[baan] hasaccepted:yes "error 1306"

# 搜索高票问答（投票数 > 10）
[baan] score:10 "your keyword"

# 搜索最近的问题
[baan] created:2024-01-01..2026-05-11 "your keyword"
```
