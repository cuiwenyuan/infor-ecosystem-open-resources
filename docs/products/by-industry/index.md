# 按行业分类

> 根据 Infor 产品在不同行业中的实际应用情况，按行业维度推荐最适合的 Infor 产品组合和相关资源。

## 制造业 (Manufacturing)

制造业是 Infor 最核心的优势领域，针对不同类型的制造模式有专门的产品方案。

### 离散制造 (Discrete Manufacturing)

**推荐产品**：**Infor LN**（主力）、**CloudSuite Industrial**（中端）

| 子行业 | 推荐产品 | 关键特性 |
|--------|----------|----------|
| **航空航天与防务** | Infor LN | ETO（工程到订单）、AS9100 合规、配置管理、长周期项目 |
| **汽车及零部件** | Infor LN | JIT/JIS 交付、序列号追踪、供应商门户、EDI 集成 |
| **高科技电子** | Infor LN | 高频工程变更、多级 BOM、CTO 配置、全球供应链 |
| **金属加工 / 机械制造** | Infor LN / CSI | 工艺路线管理、外协加工、车间作业控制 |
| **工业设备制造** | CloudSuite Industrial | 中端市场的完整制造套件，快速上线 |

### 流程制造 (Process Manufacturing)

**推荐产品**：**Infor M3**（主力，流程制造市场领导者）

| 子行业 | 推荐产品 | 关键特性 |
|--------|----------|----------|
| **食品与饮料** | Infor M3 | 配方管理、批次追踪、保质期管理、标签合规、召回管理 |
| **化工** | Infor M3 | 联产品/副产品管理、危险品合规、罐存管理、批次平衡 |
| **制药 / 生命科学** | Infor M3 | 电子批记录、FDA 21 CFR Part 11 合规、序列化监管、验证支持 |
| **时尚 / 服装 / 鞋帽** | Infor M3 Fashion | 季节性产品管理、尺码/颜色矩阵、PLM 集成、全渠道零售 |
| **包装 / 消费品** | Infor M3 | 品牌管理、促销管理、贸易促销优化 |

### 第三方物流 (3PL / Logistics)

**推荐产品**：**Infor WMS** + **Infor Nexus**

| 能力 | 说明 |
|------|------|
| **仓储运营** | Infor WMS 提供专业的 3PL 仓储管理（多客户、多计费） |
| **运输执行** | Infor Nexus 提供全球物流可视化和运输管理 |
| **供应链协同** | Nexus 连接货主、承运商和 3PL，实现端到端可视化 |

## 服务行业 (Service Industries)

Infor 在多个服务垂直行业提供了行业专属的 CloudSuite 解决方案。

### 医疗保健 (Healthcare)

**推荐产品**：**CloudSuite Healthcare**（基于 Lawson / Infor HCM）

| 关键能力 | 说明 |
|-----------|------|
| **人力资源管理** | 医护人员排班、资质管理、薪酬计算 |
| **财务管理** | 多部门/多基金财务、成本分摊、合规报告 |
| **供应链** | 医疗物资采购与库存管理 |

**相关资源**：
- [HCM/Lawson 专长顾问](../../resources/consultants.md) — Blue Eagle Consulting, RPI Consultants
