### 汽车

**加速智能汽车和电动汽车创新、提高效率并提升盈利能力。**

#### 推荐产品

| 产品 | 说明 |
|------|------|
| [Infor LN](../by-product/ln.md) | 大型汽车零部件制造商首选 |
| [CloudSuite Industrial](../by-product/csi.md) | 中端汽车零部件制造商 |
| Infor EAM | 生产设备维护管理 |

#### 核心功能
- 多级 BOM 管理（汽车组件层次结构）
- 工程变更管理（ECM）— 关键合规要求（IATF 16949）
- 序列号和批次跟踪（召回管理）
- 高级计划和调度（APS）
