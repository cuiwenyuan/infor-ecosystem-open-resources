## 📚 学习路径

### LN 实施顾问学习路径（0-12 个月）

```
阶段 1（0-3 个月）：基础
  → 完成 Infor Education LN 基础培训
  → 阅读 FullOnBaan LN Playbook
  → 搭建测试环境，完成基础配置

阶段 2（3-6 个月）：进阶
  → 深入学习制造管理模块
  → 学习 ION/BOD 集成
  → 参与 1-2 个真实实施项目

阶段 3（6-12 个月）：备考
  → 参加 Infor Education ICP 备考课程
  → 完成模拟考试
  → 预约 ICP LN 认证考试
```

### M3 实施顾问学习路径（0-12 个月）

```
阶段 1（0-3 个月）：基础
  → 完成 Infor Education M3 基础培训
  → 学习流程制造概念
  → 搭建 M3 测试环境

阶段 2（3-6 个月）：进阶
  → 深入学习 M3 API 和 ION 集成
  → 学习 XtendM3 开发
  → 参与真实实施项目

阶段 3（6-12 个月）：备考
  → 参加 ICP M3 备考课程
  → 完成模拟考试
  → 预约 ICP M3 认证考试
```

## 📌 认证备考建议

### 通用建议

1. **先积累项目经验**：认证考试侧重实战，建议先参与 1-2 个完整实施项目
2. **使用官方培训**：Infor Education 的备考课程覆盖 80%+ 考试内容
3. **搭建测试环境**：动手实践比死记硬背更有效
4. **参与社区讨论**：Infor Community 有大量实战经验分享

### 考试报名

| 步骤 | 说明 |
|------|------|
| **1. 注册 Infor Education** | 创建账号：[education.infor.com](https://education.infor.com/) |
| **2. 购买考试券** | 通过 Infor 或合作伙伴购买 |
| **3. 预约考试** | 在线监考或指定考点 |
| **4. 备考** | 使用官方培训和社区资源 |
| **5. 参加考试** | 在线考试，即时出成绩 |
