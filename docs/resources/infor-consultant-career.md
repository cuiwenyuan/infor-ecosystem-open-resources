# 如何成为 Infor LN 顾问（职业路径 · 技能 · 认证 · 薪酬）

> Infor LN（前身 Baan）是全球复杂离散制造的主力 ERP 之一，能实施、配置和支持它的顾问长期稀缺。本页梳理从入门到资深顾问的完整路径；配套阅读：[认证考试指南](certification-guide.md) · [招聘与求职](jobs.md)。

## 为什么值得入行

- **制造刚需**：LN 深度服务航空航天与国防、汽车、工业装备、高科电子等行业，客户续费与升级带来持续需求
- **供不应求**：持证且项目经验完整的 LN 顾问在全球都难招，资深顾问溢价明显
- **全球机会**：EMEA、美洲、APAC 都有大量项目，可远程、可出海（中国顾问赴墨西哥、东南亚支持项目很常见）
- **知识可迁移**：Baan 时代的老知识（会话模型、数据字典、4GL）在 LN 时代依然有效

## 四阶段职业阶梯

| 阶段 | 年限 | 典型工作 |
|------|------|---------|
| 1️⃣ 初级顾问（功能/技术） | 0–2 年 | 熟悉 LN 操作、吃透 1–2 个核心模块，辅助资深顾问做配置与用户培训 |
| 2️⃣ 模块专家（功能顾问） | 2–5 年 | 独立负责模块级工作流：fit-gap 分析、方案设计、端到端配置（生产订单 / 采购 / 财务期间）、指导新人 |
| 3️⃣ 高级顾问 / 方案架构师 | 5–10 年 | 负责完整项目流或客户主接口人：跨模块集成设计、蓝图工作坊主导、技术团队定制指导 |
| 4️⃣ 首席顾问 / 实践负责人 | 10 年+ | 主导大型/多站点交付战略、建设方法论与团队，参与售前与投标 |

## 功能线 vs 技术线

- **功能顾问**：吃透业务流程（供应链、财务、运营），把业务映射为 LN 配置。供应链 / 财务 / 运营背景是天然入口
- **技术顾问**：定制开发（[4GL](ln-4gl-tips.md)、[DAL](ln-dal-guide.md)、Extensions）、[ION 集成](ion-integration.md)、数据迁移、报表。编程 / 数据库 / IT 基础设施背景更顺手
- **双料最值钱**：功能 + 技术兼修的方案架构师费率最高

## 核心技能清单（招聘方高频要求）

**功能与技术**
- LN 模块配置：制造、财务、采购、[WMS 集成](../by-product/wms.md)、Factory Track
- 业务流程梳理与 fit-gap 分析
- [4GL 脚本与定制](../developer/ln-4gl-snippets.md)（技术线必备）
- ION 集成与 [BOD](ion-integration.md)、REST / Web Services
- 数据迁移策略与 ETL
- 报表开发：Crystal Reports、Birst、Atlas
- 多站点 / 多币种架构、MRP / APS 规划配置
- SQL 数据校验、LN 升级与补丁管理

**软技能**
- 需求调研与工作坊引导、功能规格书写作
- 项目管理基础（敏捷 / 瀑布，PMP 加分）
- 终端用户培训设计与交付
- 跨文化沟通（全球项目）、抗压与多任务

## 认证准备

Infor 通过 **Infor Campus** 提供官方认证轨道，常见方向：LN 制造、LN 财务、LN 采购与物流、LN 技术顾问（4GL 开发 / ION 集成 / 系统管理 / 性能调优）、ION 与集成认证。考试大纲、学习路径与备考建议见[认证考试指南](certification-guide.md)。

## 薪酬行情（2026 公开口径，仅供参考）

| 市场 | 角色 / 信号 | 参考区间 |
|------|-----------|---------|
| 🇨🇳 中国（杭州示例） | LN 实施顾问（高级） | **15–25K/月**（要求 5 年+ LN 经验、3 个完整项目、英语流利） |
| 🇺🇸 美国 | 高级 LN 功能顾问（NTT DATA 等） | **$110K–$153K/年**（工程与物料主数据方向） |
| 🌍 全球（伙伴费率） | 实施伙伴顾问 | **$150–300/小时**（因公司与地区而异） |
| 🇨🇳 中国（头部需求方） | ERP 项目经理 | 要求 10 年+ Baan/LN 经验、8 个以上项目管理经验（上海/广东） |

**中国市场特点**：招聘方普遍要求「Baan 或 Infor LN」10 年级经验、物流或财务二选一精通、良好的英语沟通、适应经常出差（含海外）；懂数据库（SQL/Oracle）与基础开发的顾问明显更抢手。在招职位实时信息见[招聘与求职](jobs.md)。

## 面试高频考点

- 生产计划：MPS / MRP 循环、预测消耗、供需平衡、规划主数据（物料计划属性、订单策略、时间栏、计划员）
- 多站点 / 多法人财务架构（财务公司 vs 物流公司）
- BOM / 工艺路线 / 车间控制的端到端流程
- ETO / 项目型制造的成本归集
- 4GL / Extensions 定制的边界（云升级安全）
- ION BOD 流程与常见集成故障排查
