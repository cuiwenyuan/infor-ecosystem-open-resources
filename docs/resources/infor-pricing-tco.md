# Infor 定价与 TCO 指南（CloudSuite / M3 / LN / CSI）

> 💡 **先说结论**：Infor **不公布官方价目表**，每一单都是基于用户数、CloudSuite 版本、模块范围与实施复杂度的**定制报价**（通常 3 年起、按年计费，合同内写有 3–5% 年度递增条款）。本页汇总 2026 年多家独立第三方（ERPResearch、CostBench、ERP Information、ERP Implementation 等）的估算区间，**仅供预算参考，不构成任何报价承诺**；实际数字请以 Infor 或授权伙伴的方案为准。

## 订阅许可（按命名用户 / 月）

| 方案 | 典型规模 | 订阅价参考（第三方估算） | 典型实施周期 |
|------|---------|----------------------|------------|
| **CloudSuite Industrial（CSI / SyteLine）** | 200–1,500 用户 | **$150–200 / 用户 / 月** | 14–18 个月 |
| **Infor M3（CloudSuite）** | 500–5,000 用户 | **$200–250 / 用户 / 月**（全角色 $200–400，轻量用户 $30–80） | 18–24 个月 |
| **Infor LN（CloudSuite Industrial Enterprise）** | 500–3,000 用户 | **$200–300 / 用户 / 月** | 20–24 个月 |
| **CloudSuite Distribution（CSD）** | 300–2,000 用户 | **$150–200 / 用户 / 月** | 12–18 个月 |
| **Infor CloudSuite（整体）** | — | 买方公开口径**约 $400K/年起**（4 个公开来源的估算下限） | 视范围 |

用户分级是价格的关键杠杆：Infor 按**角色分层计费**（完全用户 / 标准用户 / 轻量自助用户），车间扫码或自助查询类用户远比财务、供应链高级用户便宜。一个 100 用户的流程制造企业，仅订阅通常落在 **$180K–$400K/年**（第三方估算）。

## 实施成本（通常比订阅更贵）

| 企业规模 | 用户数 | 实施费参考（第三方估算） |
|---------|--------|----------------------|
| 小型 / 单站点 | 5–25 | $50K–$200K |
| 中型（单法人） | 25–150 | $200K–$600K |
| 中型（多法人） | 150–500 | $500K–$1.5M |
| 大型 / 多国 | 500+ | $1M–$2M+ |

**经验法则**：标准范围下实施费约为**年订阅的 1–2 倍**；多国、多法人或深度定制项目更高。伙伴顾问费率约 **$150–300/小时**（因公司与地区而异）。数据迁移经常被低估——第三方口径约 **$50K–$200K+**，取决于数据量与源系统复杂度。

## 三年 TCO 参考

以 100 用户部署为例（第三方估算口径，含许可 + 实施 + 培训）：

| TCO 组成 | 三年占比（典型） | 主要驱动因素 |
|---------|---------------|------------|
| 订阅许可 | 35–50% | 用户数、角色配比、附加模块 |
| 实施 | 30–50% | 法人数、国家数、集成、定制量 |
| 培训与变革管理 | 5–15% | 团队规模、流程变革深度 |
| 支持与合同递增 | 5–10% | 支持等级、年度递增条款 |

**参考区间**：100 用户三年 TCO 约 **$920K–$2.4M**；大型流程制造商（重度定制）仅上线前就可能超过 $2M。CostBench 建议在初始估算之上**预留 30–50% 应急预算**，并提醒 Infor CloudSuite 至少有 15 项已记录的"隐性成本"（实施、培训、附加模块、集成维护、内部团队投入等）。

## 历史本地部署（On-Premise）口径

- 存量本地部署的 M3 / LN / SyteLine 仍在支持期内，官方未公布停止支持日期
- 本地许可模式为**一次性许可 + 年维护费**（约原许可费的 **18–22%/年**），另加自有托管与升级成本
- 注意：新功能与 AI 能力**云优先甚至云专属**，本地部署的功能会逐渐落后

## 价值侧参考

Infor 委托 Forrester 做的 TEI 研究（2025，面向制造中型企业：2,000 员工、$10 亿营收）给出：三年 **ROI 114%**、**20 个月回本**、NPV $1,050 万。该研究由 Infor 资助，宜作方向性参考而非承诺。

## 降本建议（第三方共识）

1. **采用 CloudSuite 标准流程**，减少标准层之外的定制——定制是 TCO 的最大放大器
2. **分期上线**（按法人 / 按站点分波次），摊薄风险与现金流
3. **右量化用户角色**——不是每个人都需要完全用户许可
4. **在合同谈判阶段锁定多年期价格与递增上限**
5. **先定"引擎"再看演示**——M3 / LN / CSI / CSD 的选型错误会让后续所有预算失真（参见[选型对比](../competitor/ln-vs-m3.md)）
