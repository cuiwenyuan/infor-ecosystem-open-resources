# Infor LN 规划配置指南（MPS / MRP / 多站点计划）

> 规划（Enterprise Planning）是 LN 实施中最考验顾问功力的领域之一，也是面试高频考点。本页从概念到配置要点做系统梳理；具体会话操作请以官方文档为准（见[官方文档索引](official-docs.md)）。

## LN 规划体系总览

LN 的规划围绕「**物料 × 计划数据 × 订单策略**」展开：

- **MPS（主生产计划）**：由计划员驱动，决定"生产什么、何时生产"，通常对关键物料 / 瓶颈资源做主计划
- **MRP（物料需求计划）**：由 MPS 与独立需求展开，按 BOM 逐层计算相关需求，生成生产订单与采购订单建议
- **SIC（统计库存控制）**：对低价值 / 需求平稳的物料用再订货点法，省去逐项 MRP 的维护成本
- **DRP（分销需求计划）**：多站点 / 多仓网络下的跨站点供需计划，LN 原生支持多企业 / 多站点展开
- **CTP（可承诺能力）**与 **ATP（可承诺量）**：接单时回答"能不能交付、何时交付"

## 物料计划数据（Item Planning Data）

规划结果的准确性 80% 取决于计划主数据。每个"物料-仓库（或物料-站点）"组合上的关键字段：

| 数据类别 | 典型字段 | 常见坑 |
|---------|---------|--------|
| 需求侧 | 订单策略、需求计划方法 | 策略选错导致 MRP 不跑或重复建议 |
| 供应侧 | 固定/可变提前期、安全时间 | 提前期不准 → 建议订单总在救火 |
| 批量 | 批量规则（按需、固定、期间、倍数）、最小/最大量 | 批量过大 → 库存高企 |
| 库存策略 | 安全库存、服务水平、最大库存 | 安全库存层层加码 |
| 计划属性 | 计划员、计划组、MPS 项目标识 | 计划员字段缺失 → 建议无人认领 |
| 时间栏 | 计划时间栏、需求时间栏、冻结期 | 时间栏不清 → 频繁插单混乱 |

## 订单策略怎么选

| 生产模式 | 典型策略 |
|---------|---------|
| ETO / 项目制造 | 按订单（Lot-for-Lot），需求直接穿透到项目 |
| MTO | 按订单 + 采购件按需展开 |
| MTS（平稳需求） | 固定批量 / 期间批量 + 安全库存 |
| MTS（波动需求） | 期间批量 + 预测驱动的 MPS |
| 低值辅料 | SIC 再订货点，不进 MRP |

**面试常问**：预测消耗（forecast consumption）如何工作——客户订单会逐期"消耗"对应期间的预测，未消耗部分留在计划里；时间栏之后预测不再被消耗，防止远期订单扭曲主计划。

## 规划运行节奏

1. **维护计划主数据**（物料计划数据、BOM、工艺路线、库存）
2. **录入 / 接收需求**：销售订单、预测、服务件需求
3. **运行 MPS**（关键物料）→ 人工确认主计划
4. **运行 MRP** 展开相关需求 → 生成计划订单（生产 / 采购 / 转库）
5. **计划员核对建议** → 转为正式订单
6. **监控异常**：缺料信号、逾期建议、能力冲突

多站点场景由 **DRP / 企业间计划**统一展开：各站点需求汇总 → 站点间转库计划 → 中央工厂 MPS。

## 实施避坑清单（来自一线项目复盘）

- **先定企业结构，再加载主数据**——站点、企业单元、物流公司、财务公司建模推倒重来时，库存 / 订单 / 账历史都要重转换
- **提前期与批量用数据说话**——从现有 ERP / 历史记录迁移并清洗，不要拍脑袋
- **策略分层**：A 类关键物料精细管理（MPS + 人工确认），C 类物料 SIC 化，避免"全员 MRP"把计划员淹没
- **上线前用完整跨公司业务流验证**（一张从销售到采购到车间到财务的端到端单据链）
- **规划参数变更要留痕**——谁在什么时候改了时间栏 / 安全库存，审计与复盘都靠它
