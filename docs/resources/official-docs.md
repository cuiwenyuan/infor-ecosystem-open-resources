## 📌 文档使用技巧

| 场景 | 建议 |
|------|------|
| **查找特定功能** | 使用 docs.infor.com 右上角搜索框，输入 Session Code 或关键词 |
| **版本切换** | 文档 URL 中通常包含版本号（如 `/ln/10.7/`），替换即可切换版本 |
| **离线阅读** | 部分文档支持 PDF 下载（页面右上角下载图标） |
| **中文文档** | Infor LN 支持中文，其他产品部分支持；可在 URL 中切换语言（`/zh-cn/`） |
