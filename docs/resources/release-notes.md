# Infor 产品版本动态

> 持续追踪 Infor 各产品线版本更新与新功能发布，帮助您了解产品演进路线和规划升级时机。

## 📰 最新动态（2025-2026）

### ☁️ Infor CloudSuite 2026.04 — 2026 年 4 月发布（5 月对外公布）

> **本版本是 Infor 的「AI Agents」里程碑**：从单点 AI 走向可编排、可治理的多智能体生产化部署，并推出统一的 **Infor Velocity Suite**。

| 项目 | 详情 |
|------|------|
| **发布周期** | CloudSuite 2026.04（2026 年 4 月，5 月对外公布） |
| **官方发布页** | [Infor Software Release Enhancements](https://www.infor.com/products/enhancements) |
| **官方博客** | [CloudSuite Distribution April 2026](https://www.infor.com/blog/infor-cloudsuite-distribution-april-2026-release) |

**🤖 AI 主线（Infor AI 演进）**

- **Infor Industry AI Agents + Infor Agentic Orchestrator**：新增 4 个行业智能体，编排层以「supervisor-led」方式协调多个任务智能体跨业务流程协作（即原 Coleman AI 的能力演进）。
- **原生 MCP（Model Context Protocol）集成**：智能体通过 MCP Server 直连 Infor Industry Cloud Platform 应用，标准化数据与动作，便于快速部署与扩展。
- **治理与透明**：新增自动化评估框架（校验智能体响应）、Focus Mode（定向交互）、Inline Thoughts（展示推理路径，提升可解释性）。
- **Infor Velocity Suite（新套件）**：包含 Prescriptive AI use case packs（按角色/部门/流程的 AI 解决方案包）、Infor WMS Pick Path Optimization（AI 拣货路径优化，ML + 实时信号降低行走时间）、Infor CareFor Managed Services（对 Velocity Suite 免费增强）。

**📦 各产品线关键更新**

- **CloudSuite Distribution**：订单 360 度视图（Advanced Line Entry 单屏汇总可用量/替代品/upsell/定价/货源）、TWL 交叉转运控制、可定制邮件（主题+正文）、按 ship-to 地点语言翻译单据、will-call 电子签收（POD）多语言支持（加/法/西/德/瑞）。
- **CloudSuite Industrial（SyteLine）**：2026 年 4 月发布 100+ 新功能（[InforLogic 解析](https://inforlogic.com/blog/infor-syteline-april-2026-release/)）。
- **CloudSuite Service Industries 2026.04**：嵌入式 AI、角色化工作台、整合界面、更新供应链与财务工具（[Surety Systems 解析](https://www.suretysystems.com/insights/infor-cloudsuite-service-industries-guide-to-latest-release/)）。
- **Infor WMS**：AI 驱动的拣货路径优化（Infor Velocity Suite）。
- **Infor Birst**：Visualizer Builder 接入 GenAI，用户可用自然语言构建与格式化图表。
- **Infor Service Management（ISM）**：GenAI Image Recognition（现场拍照识别零件、返回常见问题与排查步骤、查库存并可直接下单）；ISM Service Manager Workspace（移动端角色视图汇总告警与关键任务）。
