## 🏆 认证指南

### Infor Certified Professional (ICP) 认证

**类型**：官方认证体系 🎓💰

**适用产品**：LN、M3、CloudSuite、HCM、EAM 等

**地区**：全球

**语言**：英文

**简介**：
Infor 官方专业认证体系，涵盖产品知识、技术实施、系统管理等多个方向。认证考试通过后获得 Infor 官方认证证书，是 Infor 顾问和技术人员的重要职业资质。

**认证方向**：
- **Implementation Professional** - 实施顾问认证
- **System Administrator** - 系统管理员认证
- **Developer** - 开发者认证
- **Sales Professional** - 销售认证（合作伙伴）

**链接**：
- 认证页面：[Infor Certifications](https://www.infor.com/company/education/certifications)
- 考试报名：通过 Infor Learning Center

**费用**：💰 付费（考试费用因认证方向而异）

## 💡 学习路径建议

### Infor LN 初学者路径

1. **ERP 基础概念** → LinkedIn Learning 或 Udemy 通用 ERP 课程
2. **LN 产品概览** → Infor Learning Center 基础课程
3. **LN 技术入门** → FullOnBaan 博客 + Infor Developer Portal
4. **4GL 编程实践** → FullOnBaan 教程 + Infor Documentation
5. **DAL 与集成** → Infor Developer Portal ION 文档
6. **认证考试** → Infor Certified Professional

### Infor M3 初学者路径

1. **M3 产品概览** → Infor Learning Center 基础课程
2. **M3 技术入门** → XtendM3 文档
3. **XtendM3 开发** → XtendM3 官方文档 + GitHub 示例
4. **M3 API 集成** → Infor Developer Portal
5. **认证考试** → Infor Certified Professional

### Infor OS/ION 开发者路径

1. **Infor OS 概览** → Infor Learning Center
2. **ION 架构理解** → Infor Developer Portal
3. **BOD 开发** → Infor Developer Portal BOD 文档
4. **API 开发** → ION API Documentation
5. **Ming.le 扩展** → Infor Developer Portal
6. **认证考试** → Infor Certified Professional - Developer
