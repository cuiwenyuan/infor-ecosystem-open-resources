# Infor 产品生态系统导航站

欢迎来到 **Infor 产品生态系统导航站**！这是一个开源项目，旨在为 Infor 客户、实施合作伙伴、开发者和内部员工提供完整、准确、易用的 Infor 产品信息和导航。

## 🎯 项目目标

- **一站式导航**：快速找到需要的 Infor 产品和解决方案
- **完整信息**：提供产品详细介绍、功能列表、技术规格、资源链接
- **多语言支持**：中英文双语，覆盖更广泛的用户群体
- **开源协作**：欢迎社区贡献，共同维护和完善

## 📚 产品分类

### 按业务功能分类

| 分类 | 说明 |
|------|------|
| **ERP 系统** | 财务、制造、供应链等核心业务管理 |
| **人力资本管理** | HCM、劳动力管理、薪资管理 |
| **企业资产管理** | EAM、设备维护、资产管理 |
| **客户关系管理** | CRM、销售自动化、客户服务 |
| **专业解决方案** | CPQ、Factory Track 等 |

### 按产品线分类

| 产品线 | 目标客户 |
|--------|----------|
| **CloudSuite Industrial** | 中端离散制造商（前 SyteLine） |
| **Infor LN** | 大型企业复杂离散制造需求 |
| **Infor M3** | 流程制造商和分销商 |

### 按行业分类

- 离散制造（汽车、电子、工业设备）
- 流程制造（食品饮料、化工、制药）
- 分销和零售
- 医疗服务
- 酒店和 hospitality

### 按技术平台分类

- Infor OS 平台
- Coleman AI（人工智能）
- Birst Analytics（商业智能）
- ION（集成中间件）
- Ming.le（协作平台）

## 🔍 快速开始

### 浏览产品

- 访问 [产品分类](products/by-function/) 页面，按业务功能浏览
- 使用搜索框快速查找产品
- 点击产品卡片查看详细信息

### 搜索产品

在页面右上角的搜索框中输入关键词，如：
- 产品名称：`Infor LN`、`Infor M3`
- 功能：`ERP`、`供应链管理`、`人工智能`
- 行业：`汽车`、`食品饮料`
