# 按行业分类

本页面按**行业**分类展示 Infor 产品和解决方案，帮助您快速找到适合您行业的解决方案。

**加速智能汽车和电动汽车创新、提高效率并提升盈利能力。**

#### 推荐产品组合

| 产品 | 说明 |
|------|----------|
| [Infor LN](details/infor-ln.md) | 大型汽车零部件制造商首选 |
| [CloudSuite Industrial](details/cloudsuite-industrial.md) | 中端汽车零部件制造商 |
| [Infor EAM](../../ecosystem/) | 生产设备维护管理 |
| [Infor SCM](../../products/by-function/) | 供应链优化 |

#### 核心功能

- ✅ 多级 BOM 管理（汽车组件层次结构）
- ✅ 工程变更管理（ECM）- 关键合规要求
- ✅ 质量管理（IATF 16949 合规）
- ✅ 序列号和批次跟踪（召回管理）
- ✅ 高级计划和调度（APS）
