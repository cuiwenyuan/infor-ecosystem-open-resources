# Infor LN

![Infor LN Logo](../../assets/images/infor-ln.png)

## 产品概述

**Infor LN** 是一款面向大型企业复杂离散制造需求的 ERP 解决方案，支持多站点、多实体运营，提供强大的制造管理和供应链优化能力。

- **产品类型**: ERP 系统
- **产品线**: Infor LN
- **目标客户**: 大型企业（500-10,000+ 员工）
- **核心行业**: 汽车、工业制造、电子、金属加工

## 核心功能

### 制造管理
- ✅ 多级 BOM（物料清单）管理
- ✅ 工艺路线和工作中心管理
- ✅ 工作订单管理
- ✅ 物料需求计划（MRP）
- ✅ 高级计划和调度（APS）
- ✅ 工程变更管理（ECM）
- ✅ 配置到订单（CTO）场景的产品配置器
- ✅ 外协加工（分包制造）

### 供应链管理
- ✅ 采购管理
- ✅ 库存管理
- ✅ 质量管理
- ✅ 序列号和批次跟踪

### 财务管理
- ✅ 总账（GL）
- ✅ 应付账款（AP）
- ✅ 应收账款（AR）
- ✅ 现金管理
- ✅ 固定资产

## 适用场景

### ✅ 适合的企业

- 大型离散制造商（500+ 员工）
- 复杂的多站点、多实体运营
- 需要高级计划和调度（APS）的企业
- 需要工程变更管理（ECM）的企业
- 需要配置到订单（CTO）的企业

### ❌ 不适合的企业

- 小型企业（< 500 员工）— 考虑 CloudSuite Industrial
- 流程制造（食品、化工等）— 考虑 Infor M3
- 简单制造需求 — 考虑更简单的 ERP 解决方案

## 集成能力

Infor LN 可以通过以下方式与第三方系统集成：

### Infor ION（推荐）
- 基于事件的消息传递
- 预构建连接器（EDI、银行、税务等）
- API 管理
- 工作流编排

### 直接 API 集成
- REST API
- SOAP API
- 数据库直连（需谨慎）
