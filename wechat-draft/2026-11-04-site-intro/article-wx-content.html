用 Infor 的人，多少都经历过这样的时刻。

想找一个 LN 的 Session 用法，官方文档入口深、界面以英文为主；想找一家靠谱的实施顾问，不知道圈子里有谁、擅长什么；想看别人怎么踩坑，又不知道哪些博客和技术社区还活着。

资源不是没有，而是散落在世界各地、各种语言、各种角落。

今天正式介绍一下我们维护的开源项目——infor-ecosystem-open-resources（Infor 生态开放资源导航站）：把 Infor 生态里值得用的第三方资源，分门别类收进一个站点，免费开放给所有 Infor 用户、实施顾问、开发者和学习者。

一、它是什么，不是什么

一句话定位：第三方资源导航站，不是官方文档站。

✅ 收录：第三方论坛与社区、全球实施顾问公司、技术博客与教程、开发工具与插件、培训与认证资源

❌ 不收录：官方产品文档（请直达 docs.infor.com）、营销广告内容、与 Infor 生态无关的站点

所有资源经过筛选和整理，附中英文说明，按类型、产品、行业、地区四个维度组织，找东西像查目录一样直接。

每个条目都有统一格式的介绍：资源是什么、适合谁、怎么用——不堆链接，做有信息量的导航。

三、按产品逛：10 大产品页，四种分类视角

Infor 产品线庞杂，导航站按产品整理了 LN、M3、CloudSuite Industrial、WMS、Factory Track、MES、HCM、EAM、CRM、Infor OS 共 10 个产品详情页，每个产品页交叉串联四类资源（社区、顾问、博客、工具）。

📦 按产品线：LN / M3 / CSI / EAM / WMS 等

🏗️ 按行业：制造、分销、医疗、酒店、公共事业

⚙️ 按技术平台：Infor OS、ION、Birst、AI、AWS

不管你是「用 LN 的财务」还是「做 M3 的开发」，都能几步跳到自己关心的资源。

四、开发者专区：查 Session 不用再翻文档树

💡 LN 4GL 代码片段库：常用 4GL/DAL2 代码模式，附讲解

💡 API 开发指南：ION API、Infor OS 接口开发资源

💡 故障代码百科：LN 常见错误速查与解决思路

💡 LN Session 速查页：基于官方多版本文档采集 12,125 条 Session，覆盖 23 个包、208 个模块组，支持中英文模糊搜索、按包/模块联动筛选，每条附 10.7 / 10.6 / 10.8 / 2024.x Cloud / 2025.x Cloud 多版本官方文档直达链接

其中 Session 速查页上线后持续扩充，已覆盖五个官方文档版本——输入关键字马上找到 Session，客户现场、写定制代码时都很好用。

五、中文用户专区

面向中文用户专门做了中国专区：中文技术资源、国内顾问与实施公司、中文培训与社群（微信公众号、知识星球）一站汇总。

另有 Infor 中英术语表：产品、技术、行业术语对照查询，看英文文档卡壳时很有用。
