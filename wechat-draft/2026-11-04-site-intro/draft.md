## 正文

### 导语

用 Infor 的人，多少都经历过这样的时刻：想找一个 LN 的 Session 用法，官方文档入口深、全英文；想找个靠谱的实施顾问，不知道圈子里有谁；想看别人怎么踩坑，不知道哪些博客还活着。

资源不是没有，而是**散落在世界各地、各种语言、各种角落**。

今天正式介绍一下我们维护的开源项目——**infor-ecosystem-open-resources**（Infor 生态开放资源导航站）：把 Infor 生态里值得用的第三方资源，分门别类地收进一个站点，免费开放给所有 Infor 用户、实施顾问、开发者和学习者。

### 一、它是什么，不是什么

一句话定位：**第三方资源导航站，不是官方文档站**。

- ✅ 收录：第三方论坛与社区、全球实施顾问公司、技术博客与教程、开发工具与插件、培训与认证资源
- ❌ 不收录：官方产品文档（请直达 docs.infor.com）、营销广告内容、与 Infor 生态无关的站点

所有资源经过筛选和整理，附中英文说明，按类型、产品、行业、地区四个维度组织，找东西像查目录一样直接。

### 二、六大资源板块，240+ 精选资源

| 板块 | 数量 | 收录内容 |
|---|---|---|
| 论坛与社区 | 30 个 | Infor User Community、独立用户组（TUG 等）、Reddit、LinkedIn 群组 |
| 顾问与实施公司 | 55 家 | 全球 Infor 实施合作伙伴目录，附地区与擅长产品 |
| 博客与教程 | 66 个 | 技术博客、视频教程、学习路线 |
| 工具与插件 | 66+ 个 | 开发工具、第三方插件、实用脚本 |
| 培训与认证 | 20+ 个 | 官方/第三方培训资源、认证指南 |
| 官方文档导航 | 按产品 | docs.infor.com 各产品直达入口 |

每个条目都有统一格式的介绍：资源是什么、适合谁、怎么用，不堆链接，做有信息量的导航。

### 三、按产品逛：10 大产品页，四种分类视角

Infor 产品线庞杂，导航站按产品整理了 LN、M3、CloudSuite Industrial、WMS、Factory Track、MES、HCM、EAM、CRM、Infor OS 等 **10 个产品详情页**。

每个产品页交叉串联四类资源（社区、顾问、博客、工具），并支持四种分类视角切换：

- 🏭 按业务功能：财务、供应链、制造、HCM、CRM、资产管理
- 📦 按产品线：LN / M3 / CSI / EAM / WMS 等
- 🏗️ 按行业：制造、分销、医疗、酒店、公共事业
- ⚙️ 按技术平台：Infor OS、ION、Birst、AI、AWS

不管你是「用 LN 的财务」还是「做 M3 的开发」，都能几步跳到自己关心的资源。

### 四、开发者专区：这次更新的主角

针对 Infor 开发者，站点设了专门的**开发者资源中心**：

- **LN 4GL 代码片段库**：常用 4GL/DAL2 代码模式，附讲解
- **API 开发指南**：ION API、Infor OS 接口开发资源
- **故障代码百科**：LN 常见错误速查与解决思路
- **LN Session 速查页**（上周新增）：基于官方多版本文档采集 **12,125 条 Session**，覆盖 23 个包、208 个模块组，支持中英文模糊搜索、按包/模块联动筛选，每条附多版本官方文档直达链接——查 Session 不用再翻文档树了

### 五、中文用户专区

面向中文用户专门做了**中国专区**：中文技术资源、国内顾问与实施公司、中文培训与社群（微信公众号、知识星球）一站汇总；另有 **Infor 中英术语表**，产品、技术、行业术语对照查询，看英文文档卡壳时很有用。

### 六、完全开源，欢迎参与

整个项目托管在 GitHub，**完全免费、无广告、不设门槛**：

- 在线地址：cuiwenyuan.github.io/infor-ecosystem-open-resources
- 开源仓库：github.com/cuiwenyuan/infor-ecosystem-open-resources
- 技术栈：MkDocs + Material 主题，GitHub Pages 自动部署

发现好资源？欢迎通过 GitHub 提 Issue 或 Pull Request 推荐收录；发现链接失效也欢迎反馈，站点会持续更新维护。

### 结尾

做这个站没有商业目的，只是把 Infor 圈子里散落的好东西攒到一起，让后来的人少走点弯路。

**收藏一个站，找 Infor 资源不再东搜西找。**
